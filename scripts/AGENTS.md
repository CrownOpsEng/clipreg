# Tooling/deployment agent router

Before changing `scripts/` or deployment behavior, read:

1. `../docs/deployment.md` — install/upgrade/autostart/migration authority.
2. `../docs/release.md` — version/tag/release authority.
3. `../docs/foundation.md` — remote safety, generated files, and PR rules.
